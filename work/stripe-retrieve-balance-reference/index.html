Overview

This is a single-endpoint API reference page for Stripe’s Retrieve balance endpoint, which returns the money in a Stripe account that is available to pay out and the money that is still pending. It is written for developers integrating with Stripe’s API. I wrote it in Markdown as a practice sample from Stripe’s public API documentation. It is not an official Stripe document.

My approach

The page follows the order a developer works in: what the endpoint does, how to call it, what comes back, and what to do when it fails. Each section answers one question, with a copyable request, a full response example, and tables for the endpoint, response fields, and errors. I explained the details that trip people up, such as amounts in the smallest currency unit and the colon after the key in the curl example, and kept the source in Markdown so it can be reviewed and versioned in Git like code.
